# D01.34 斗鱼贵宾数显示为在线数（接 D01.3）

- 类型：平台
- 来源：用户 2026-10-28
- 相关：D01.3、E01.2、决定 D-068

## 目标

斗鱼弹幕里的贵宾数不再以“贵宾”聊天行出现在弹幕列表，改为显示在直播间的热度、已开播那一栏（像哔哩哔哩的“在线”）；数据仍从弹幕 ws 的 `oni` 包取。

## 做法

`DouyuDanmakuProtocol` 把 `oni` 的 `vn` 报成 `LiveMessageType.online`，数据 `LiveAudienceUpdate(kind: onlineViewers)`；只收本房间的，空数字或非数字不报。应用（`room_controller.dart` 的 `_applyAudience`）已有这条通路，观众栏和详情页直接显示，不改界面。`oun` 仍不上报。

## 验收

1. 斗鱼弹幕列表里不再出现“贵宾”聊天行。
2. 直播间观众栏（和详情页）出现“在线 + 人数”，每收到一次 `oni` 更新一次。
3. 别的房间的 `oni`、空数字或非数字不显示。
4. 哔哩哔哩等其他平台不变。
