# A12.7 WebDAV 自动备份设置

- 状态：以登记表为准
- 类型：界面
- 来源：V01.9（D-057）、A12.5
- 相关：J04.2 逻辑

## 界面

入口：WebDAV 页顶栏 ⋮ 菜单新增“自动备份”，图标 `AppIcons.autoSync`。

对话框标题“自动备份”，图标 `AppIcons.autoSync`，宽版（最长 560）：

1. “应用运行时自动备份”开关，副标题“只在应用运行时检查；退到后台或关闭应用后不备份。”
2. “备份间隔”：每 1/6/12/24/48/72/168 小时；当前值不在选项里时补一项。
3. “备份内容”：全部设置 / 仅关注。
4. “保留份数”：1/3/7/15/30；当前值不在选项里时补一项。
5. “远程文件夹”：文本框，默认 `purelive`，帮助文字“服务器地址下的相对路径，例如 purelive 或 backup/purelive；不随当前浏览目录变化。”；保存时校验空、`.`、`..`、反斜杠和控制字符。
6. “包含账号”：开关，默认关，说明 Cookie 和 WebDAV 密码会写入上传文件；备份内容为“仅关注”时禁用并说明原因。
7. “上次成功：yyyy-MM-dd HH:mm”或“还没有成功备份过”。
8. 没有选服务器时用错误色提示，但不阻止保存。

底部“取消”“保存”；保存时按钮转圈，成功后关闭并提示“自动备份设置已保存”，失败保留对话框并提示。

## 状态

- 默认关闭，所有值来自设置。
- 没有服务器：显示提示。
- 文件夹无效：字段下显示错误，不关闭。
- 保存失败：提示重试。
- 上次没有成功：显示“还没有成功备份过”。

## 测试

- 从 ⋮ 打开对话框。
- 默认值正确。
- 修改开关、间隔、内容、保留份数、文件夹后保存，6 个设置一起写入。
- 内容为“仅关注”时账号开关禁用。
- 无效文件夹不保存并显示错误。
- 无服务器提示。
