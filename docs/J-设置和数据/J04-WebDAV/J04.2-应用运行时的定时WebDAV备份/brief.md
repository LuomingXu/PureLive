# J04.2 任务书：应用运行时的定时 WebDAV 备份

## 目标

给现有手动 WebDAV 上传增加“应用运行时按间隔自动上传”，不改手动上传。

## 必须做到

- 6 个新设置，默认：关、24 小时、全部设置、`purelive`、保留 7 份、不含账号。
- 自动文件名 `purelive_auto_<时间>.txt` / `purelive_favorites_auto_<时间>.txt`，手动文件不改名。
- 远程目录默认服务器根目录下的 `purelive`，可改相对路径；逐层创建目录。
- 启动补跑、运行中约每 15 分钟检查、回前台补跑；只在主窗口启动。
- 成功后弹应用内通知；失败本次运行第一次弹一次，之后只日志。
- 保留份数只清理自动文件。
- 只上传，不自动恢复。
- 加测试：文件名/保留正则、目录校验、到期和退避、上传和 meta、失败、MKCOL、设置界面。

## 不做

- WorkManager/后台服务。
- 自动下载恢复。
- 修改手动上传的目标目录和文件名。
- 修改 3.x 的设置键。

## 验收

- 定向测试和 `bash tools/gate/gate.sh --all` 通过（本机缺 Flutter 时由维护者补跑）。
- 本机临时 WebDAV 上按 README 的步骤走通。
